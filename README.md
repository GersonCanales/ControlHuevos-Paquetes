# Paquetes cifrados de Control de Huevos

Estos archivos `.bin` son paquetes cifrados para el mecanismo de actualización de Control de Huevos. No son APK que puedan instalarse directamente.

La aplicación recupera la información necesaria para abrirlos mediante una sesión habilitada del negocio. Este repositorio no contiene claves de descifrado, credenciales ni registros del negocio.

Las APK originales se distribuyen de forma privada. La instalación de cualquier actualización requiere confirmación de Android.
